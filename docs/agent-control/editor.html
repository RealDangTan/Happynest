KHÔNG ĐƯỢC PHÁ

7 luật an toàn

    KNOWBS / NGƯỠNG

    Các núm vặn hành vi

    Số nhỏ = agent đi nhanh, rẻ, nông. Số lớn = điều tra sâu hơn, tốn hơn. Knob có tên bắt đầu bằng _ là hằng số trong code — Claude Code sẽ sửa nodes.py cho bạn.

    TOOLBOX

    Công cụ planner được phép chọn

    Tắt một tool = planner không còn thấy nó trong danh sách khi điều tra.

    PROMPTS

    Lời chỉ dẫn cho AI ở từng trạm

    Chỉ trạm llm có prompt. Đổi text ở đây = đổi cách agent nghĩ ở trạm đó.

    MỤC ĐÍCH TRẠM

    Ghi chú purpose

    Mô tả hiển thị trong schema — không ảnh hưởng code runtime, dùng để ghi chú theo cách bạn hiểu.

    CẤU TRÚC

    Đường đi giữa các trạm (edges)

    ⚠️ Thêm/bớt node hoặc edge = thay đổi cấu trúc graph LangGraph — cần Claude Code sửa graph.py và có thể reset checkpoint các run đang dở. Sửa chừng mực.
    JSON THÔ

    Toàn bộ schema

    Sửa trực tiếp cho các thay đổi nâng cao (thêm node, đổi output_schemas…). Lỗi cú pháp sẽ bị chặn khi xuất.
